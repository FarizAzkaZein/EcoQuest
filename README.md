# 🌱 EcoQuest
### Interactive Environmental Education Platform

**Learn Today, Grow Tomorrow, Protect Our Earth.**

EcoQuest merupakan platform edukasi lingkungan berbasis website interaktif yang dirancang untuk meningkatkan pengetahuan, kesadaran, dan kepedulian masyarakat terhadap kelestarian lingkungan.

Platform ini menggabungkan materi edukasi, kuis interaktif, pustaka digital, informasi dampak lingkungan, serta sistem pohon virtual bernama **Hutanku**. Melalui sistem tersebut, pengguna dapat melihat perkembangan pohon virtual dari tahap benih hingga menjadi pohon yang lebat seiring dengan kemajuan aktivitas pembelajaran.

EcoQuest menghadirkan pengalaman belajar yang lebih menarik, informatif, dan interaktif melalui dua mode penggunaan, yaitu Guest dan Login.

## 🎯 2. Latar Belakang dan Tujuan

Kesadaran terhadap pentingnya menjaga lingkungan perlu dibangun melalui edukasi yang mudah diakses dan menarik. Namun, penyampaian informasi lingkungan tidak selalu cukup untuk mendorong keterlibatan pengguna dalam proses pembelajaran.

EcoQuest dikembangkan sebagai salah satu media pembelajaran alternatif yang menggabungkan informasi edukatif dengan elemen interaktif dan visualisasi perkembangan.

### Tujuan Pengembangan

- Meningkatkan pengetahuan dan kesadaran mengenai lingkungan.
- Menyediakan media edukasi lingkungan yang interaktif.
- Mendorong kebiasaan yang lebih bertanggung jawab terhadap lingkungan.
- Menghadirkan pengalaman belajar melalui kuis dan pustaka digital.
- Memvisualisasikan perkembangan pembelajaran melalui pohon virtual Hutanku.

## ✨ 3. Fitur Utama

### 3.1. Educational Materials

Menyediakan materi edukasi mengenai lingkungan, permasalahan ekologis, dan pentingnya menjaga kelestarian alam.

### 3.2. Interactive Quiz

Fitur kuis interaktif yang memungkinkan pengguna menguji pemahaman terhadap materi lingkungan yang dipelajari.

### 3.3. Digital Library

Pustaka digital yang menjadi tempat untuk mengakses berbagai informasi dan bahan bacaan mengenai lingkungan.

### 3.4. Environmental Impact

Bagian yang menyajikan informasi mengenai dampak aktivitas manusia terhadap lingkungan serta pentingnya tindakan pelestarian.

### 3.5. Virtual Tree — Hutanku

Hutanku merupakan fitur visualisasi perkembangan pohon virtual yang terhubung dengan progres aktivitas pengguna.

Pohon virtual berkembang melalui beberapa tahapan:

1. Benih.
2. Tunas.
3. Bibit.
4. Pohon muda.
5. Pohon yang tumbuh lebat.

Perkembangan visual pohon menyesuaikan progres pengguna dalam menyelesaikan aktivitas pembelajaran.

### 3.6. Guest Mode

Memungkinkan pengunjung menjelajahi website tanpa perlu memasukkan informasi login.

### 3.7. Login Mode

Memungkinkan pengguna memasukkan nama untuk menggunakan mode pengguna dan menyimpan progres pembelajaran melalui browser.

> Catatan: Sistem login saat ini merupakan simulasi frontend dan belum menggunakan autentikasi akun berbasis server.

Ikuti langkah-langkah berikut untuk mendapatkan source code EcoQuest.

Buka terminal atau Command Prompt, kemudian jalankan:


### B. Masuk ke Folder Proyek


### C. Buka Proyek

Jika menggunakan Visual Studio Code:

Jika perintah tersebut tidak tersedia, buka Visual Studio Code secara manual, kemudian pilih folder EcoQuest.

Pastikan file utama tersedia:

```text
│

    └── (gambar, ikon, dan aset pendukung)
```

> Struktur folder `assets` merupakan contoh. Sesuaikan dengan struktur aktual repository.

## ▶️ 7. Panduan Menjalankan Program

EcoQuest dapat dijalankan dengan dua cara.

### Metode 1 — Menggunakan Browser

1. Buka folder proyek EcoQuest.
2. Temukan file `index.html`.
3. Klik dua kali file tersebut.
4. Website akan terbuka menggunakan browser default.
5. EcoQuest siap digunakan.

### Metode 2 — Menggunakan Visual Studio Code dan Live Server

Metode ini direkomendasikan selama proses pengembangan.

1. Buka folder EcoQuest menggunakan Visual Studio Code.
2. Buka menu Extensions.
3. Cari ekstensi **Live Server**.
4. Instal ekstensi tersebut jika belum tersedia.
5. Buka file `index.html`.
6. Klik kanan pada area editor.
7. Pilih **Open with Live Server**.
8. Website akan terbuka melalui browser.

Live Server membantu menjalankan website melalui server lokal sehingga perubahan file dapat ditampilkan setelah disimpan.

## 💾 9. Sistem Penyimpanan Data

EcoQuest menggunakan **Browser LocalStorage** untuk menyimpan data tertentu, seperti progres pengguna yang didukung oleh implementasi aplikasi.

Karakteristik penyimpanan:

- Data tersimpan pada browser dan perangkat yang digunakan.
- Data tidak otomatis tersinkronisasi ke perangkat lain.
- Data dapat hilang apabila penyimpanan browser dibersihkan.
- Sistem belum menggunakan database online.
- Login belum menggunakan autentikasi server.

Pengguna disarankan menggunakan browser dan perangkat yang sama untuk mempertahankan progres lokal.
